MATTER — архив сайта для переноса
Версия: 2026-11-05, с полноэкранным раскрытием «Поля притяжения».

РАЗМЕЩЕНИЕ НА ХОСТИНГЕ
Распакуйте ZIP и загрузите его содержимое в корневую папку сайта.
Файл index.html должен находиться в корне, остальные файлы — рядом с ним.
Можно использовать любой хостинг статических HTML/CSS/JavaScript сайтов.
Сборка, npm, база данных и серверная часть не требуются.
Настройка перенаправлений для разделов не нужна: используются якоря #field и т. п.
Рекомендуется HTTPS. Настройки приватного доступа прежнего хостинга в архив не входят;
доступ к сайту задаётся на новом хостинге.

ПРОСМОТР НА КОМПЬЮТЕРЕ
Если установлен Python, откройте терминал в распакованной папке и выполните:
python -m http.server 4173
Затем откройте http://localhost:4173/ в браузере.
Простое открытие index.html двойным щелчком может блокировать JavaScript-модули.

СОДЕРЖИМОЕ
index.html — страница и тексты.
styles.css, app.js — оформление и взаимодействия.
sculpture.js, studies.js — анимированные исследования.
object-viewer.js, object-viewer.css, object-geometry.js, scene-catalog.js — 3D и материалы.
commerce.js, commerce.css, commerce-config.js — подготовка брифа и публичные контакты.
kinetic.js, scroll.js, world.js — сохранённые старые файлы; текущая страница их не загружает.

ШРИФТЫ И ФУНКЦИИ
Шрифты Manrope и Prata загружаются из Google Fonts; без интернета используются
системные шрифты. Модели создаются локальным кодом, внешние 3D-файлы не нужны.
При недоступном WebGL показываются запасные иллюстрации.
Без JavaScript доступны текст и статичные иллюстрации, но не 3D-просмотр и бриф.

КОНТАКТЫ И ЗАКАЗЫ
В commerce-config.js пока пустые публичные поля contactEmail, telegramUrl,
paymentUrl, paymentOffering. Заполняйте их только своими реальными контактами
и ссылками; секретные ключи в файлы сайта помещать нельзя.
Сейчас бриф можно подготовить, скачать или скопировать. Отправка владельцу
и приём оплаты не подключены. Для буфера обмена может потребоваться HTTPS
или localhost; предусмотрен ручной вариант копирования.
