# MATTER

Авторская практика интерактивного дизайна: форма, типографика и цифровое пространство, реагирующие на движение пользователя.

**Live:** https://matter-e13z.onrender.com  
**Repository:** https://github.com/NUrik20071/Matter

## Концепция

MATTER — самостоятельный интерактивный портфолио-сайт, построенный вокруг трёх визуальных исследований:

1. **Поле притяжения** — процедурная графическая поверхность.
2. **Типографика как материал** — интерактивная деформация формы букв.
3. **От жеста к резонансу** — графическое исследование света и ритма.

Каждое исследование дополнено авторской 3D-концепцией. 3D-просмотрщик использует WebGL и поддерживает управление мышью и сенсорными жестами.

## Технологии

- HTML, CSS и нативные JavaScript ES-модули.
- Canvas 2D для процедурной графики.
- WebGL для интерактивных 3D-сцен.
- IntersectionObserver и ResizeObserver для управления видимостью и размерами.
- prefers-reduced-motion и пользовательская настройка движения.
- Без обязательной сборки, Node.js, npm или базы данных.

## Структура

- `index.html` — семантическая структура и контент.
- `styles.css` — адаптивная визуальная система.
- `app.js` — взаимодействия и управление сценами.
- `studies.js` — три графических исследования.
- `object-viewer.js` и `scene-catalog.js` — WebGL-просмотрщик и каталог сцен.
- `commerce.js`, `commerce.css`, `commerce-config.js` — интерфейс брифа и настройки контактных каналов.

## Локальный запуск

Это статический сайт. Откройте репозиторий через любой локальный HTTP-сервер. Например:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

## Публикация

Проект опубликован как **Render Static Site** из корня репозитория:

- Branch: `main`
- Build command: пустая
- Publish directory: `.` (корень репозитория; в настройках Render — `.`)
- Auto deploy: при коммите в подключённую ветку

## Ограничения и честное описание

- Форма брифа пока не отправляет заявки на сервер. Она предназначена для подготовки и сохранения текста брифа на стороне пользователя.
- Контактные каналы и платёжные ссылки задаются отдельно в `commerce-config.js`; пустые значения не заменяются вымышленными данными.
- Материалы, освещение и тени в WebGL — стилизованные визуальные приближения, а не физически точная симуляция.
- Три исследования и 3D-объекты — авторские концепции, не клиентские кейсы.

## Развитие

Приоритеты: доступность и клавиатурная навигация, мобильная устойчивость WebGL, производительность, SEO и метаданные, затем — реальный безопасный канал получения заявок с явным согласием владельца на публикацию контактов.
